# v2.0.0 多语言和多用户多公司模式设计与实现

## 一、概述

本功能为系统添加完整的多语言支持和多用户多公司模式配置管理。基于现有系统架构进行扩展，保持后向兼容性。

## 二、已完成的工作

### 2.1 数据库设计

#### 2.1.1 新增表

**sys_language** - 语言配置表
- 支持系统级（公司ID=0）和公司级自定义语言
- 包含语言代码、名称、是否默认语言、是否激活
- 完整的审计字段

**sys_translation** - 翻译配置表
- 翻译键值存储，支持按语言分组
- 支持模块级组织（common, login, cloud, live等）
- 完整的审计字段

#### 2.1.2 扩展表

**sys_company** - 公司表扩展字段
- Logo - 公司Logo
- Address - 地址
- Contact - 联系人
- Phone - 联系电话
- Email - 联系邮箱

**sys_company_conf** - 公司配置表扩展字段
- DefaultLanguage - 默认语言
- Timezone - 时区
- Currency - 货币
- MaxStorageSize - 最大存储大小
- MaxFileSize - 最大文件大小
- MaxFiles - 最大文件数

**sys_user** - 用户表扩展字段
- Timezone - 用户时区
- Currency - 用户货币

## 四、使用说明

### 4.1 数据库初始化

```bash
# 执行SQL脚本
mysql -u root -p skyserver < sqls/sys_language.sql
mysql -u root -p skyserver < sqls/sys_translation.sql
mysql -u root -p skyserver < sqls/alter_sys_company.sql
mysql -u root -p skyserver < sqls/alter_sys_company_conf.sql
mysql -u root -p skyserver < sqls/alter_sys_user.sql
```

### 4.2 API使用

```
# 获取语言列表
GET /api/v1/languages

# 获取翻译列表
GET /api/v1/languages/translations?language=en-US&module=common

# 获取单个翻译
GET /api/v1/languages/translations/common.save?language=en-US

# 添加翻译
POST /api/v1/languages/translations
{
  "key": "common.save",
  "language": "en-US",
  "value": "Save",
  "module": "common"
}

# 更新翻译
PUT /api/v1/languages/translations/1
{
  "id": 1,
  "key": "common.save",
  "language": "en-US",
  "value": "Save",
  "module": "common"
}

# 删除翻译
DELETE /api/v1/languages/translations/1

# 导出翻译
GET /api/v1/languages/translations/export?language=en-US

# 导入翻译
POST /api/v1/languages/translations/import
Form-data: file=<JSON文件>, language=en-US
```

## 五、架构设计

### 5.1 多语言架构

- **前端i18n** - 基于 `vue-i18n`，支持本地语言包
- **后端翻译API** - 提供动态翻译支持，可后台编辑
- **翻译缓存** - Redis缓存翻译结果，提升性能
- **回退策略** - 语言回退到默认语言，翻译键回退到键本身

### 5.2 多租户架构

- **域名识别** - 通过请求域名自动识别公司
- **公司隔离** - 所有数据表含 SYS_COMPANY_ID 字段
- **公司级配置** - 每个公司可独立配置语言、存储等
- **级联回退** - 公司级配置回退到系统级配置

## 六、技术要点

1. **GORM实体映射** - 使用 `gorm` 标签进行数据库字段映射
2. **Redis缓存** - 翻译结果缓存，提升查询性能
3. **中间件集成** - 域名识别、语言识别中间件
4. **JSON导入导出** - 支持批量翻译导入导出
