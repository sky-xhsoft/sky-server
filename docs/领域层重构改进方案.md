## 架构设计方案

### 领域实体设计

```go
// Entity 领域实体基类
type Entity struct {
    ID         uint
    Version    int
    CreatedAt  time.Time
    UpdatedAt  time.Time
    DeletedAt  *gorm.DeletedAt
}

// AggregateRoot 聚合根接口
type AggregateRoot interface {
    GetID() uint
    GetVersion() int
    GetEvents() []*DomainEvent
    ClearEvents()
    AddEvent(event *DomainEvent)
}
```

### 领域值对象

值对象是不可变的，通过值来判断相等性：

```go
// 典型的值对象示例
type Money struct {
    Amount   decimal.Decimal
    Currency string
}

func (m Money) Equals(other Money) bool {
    return m.Amount.Equal(other.Amount) && m.Currency == other.Currency
}

func (m Money) Add(other Money) Money {
    if m.Currency != other.Currency {
        panic("currency mismatch")
    }
    return Money{
        Amount:   m.Amount.Add(other.Amount),
        Currency: m.Currency,
    }
}
```

### 领域服务

领域服务封装不属于单个实体的业务逻辑：

```go
// 示例：用户认证领域服务
type AuthenticationService struct {
    userRepo UserRepository
    hasher   PasswordHasher
}

func (s *AuthenticationService) Authenticate(
    ctx context.Context,
    username string,
    password string,
) (*User, error) {
    user, err := s.userRepo.FindByUsername(ctx, username)
    if err != nil {
        return nil, ErrInvalidCredentials
    }

    if !s.hasher.Verify(password, user.PasswordHash) {
        return nil, ErrInvalidCredentials
    }

    user.RecordLogin()
    _ = s.userRepo.Save(ctx, user)

    return user, nil
}
```

### 领域事件

领域事件表示领域中发生的重要事情：

```go
// DomainEvent 领域事件
type DomainEvent struct {
    EventID   string
    EventType string
    SourceID  string
    Data      interface{}
    Timestamp time.Time
    Version   int
}

// 示例事件：用户登录
type UserLoggedIn struct {
    UserID    uint
    Username  string
    IPAddress string
    LoginTime time.Time
}

// EventHandler 事件处理器
type EventHandler interface {
    Handle(event *DomainEvent) error
    GetSupportedEvents() []string
}
```

## 核心领域模块

### 1. SSO领域

**文件结构**:
```
internal/domain/
├── base.go           # 领域基类
├── event.go          # 事件机制
├── sso.go            # SSO领域
├── user.go           # 用户领域
└── permission.go     # 权限领域
```

**核心接口**:
- `SSOService` - 单点登录服务
- `UserService` - 用户管理服务
- `PermissionService` - 权限验证服务

### 2. 元数据领域

**核心实体**:
- `Table` - 表定义
- `Column` - 列定义
- `TableRef` - 表关联
- `Action` - 自定义动作

**领域服务**:
- `MetadataService` - 元数据管理
- `FormRenderService` - 表单渲染服务

### 3. 工作流领域

**核心实体**:
- `Workflow` - 工作流定义
- `WorkflowInstance` - 工作流实例
- `WorkflowTask` - 工作流任务

**领域服务**:
- `WorkflowEngine` - 工作流引擎

- 业务逻辑更清晰，封装在领域层

- 领域专家更容易理解代码

- 支持复杂业务场景

- 与框架解耦
- 支持CQRS和事件溯源
- 更好的可扩展性
