# 仓储层重构改进方案

## 1. 当前架构分析

### 现有架构优点
- ✅ **接口优先设计** - 每个Repository都有接口定义
- ✅ **分层架构** - 接口与实现分离，解耦良好
- ✅ **依赖注入** - 通过构造函数注入依赖
- ✅ **ORM框架** - 使用GORM简化数据库操作
- ✅ **错误处理** - 实现了基础的错误处理

### 可改进的地方
- ❌ **缺少缓存策略** - 没有实现缓存层
- ❌ **缺少事务管理** - 没有统一的事务边界管理
- ❌ **缺少单元测试** - 没有对Repository进行测试覆盖
- ❌ **缺少查询优化** - 没有实现复杂查询的优化策略
- ❌ **缺少分页封装** - 没有统一的分页查询接口

## 3. 架构设计方案

### 3.1 Repository基类设计
```go
// BaseRepository 基础Repository实现
type BaseRepository struct {
	db          *gorm.DB
	cache       cache.Cache
	logger      *zap.Logger
	cacheTTL    time.Duration
}

// NewBaseRepository 创建基础Repository实例
func NewBaseRepository(db *gorm.DB, cache cache.Cache, logger *zap.Logger) *BaseRepository {
	return &BaseRepository{
		db:          db,
		cache:       cache,
		logger:      logger,
		cacheTTL:    5 * time.Minute,
	}
}

// 提供通用查询、分页、缓存等功能
func (r *BaseRepository) GetByID(ctx context.Context, entity interface{}, id uint) error { ... }
func (r *BaseRepository) GetList(ctx context.Context, entity interface{}, filters interface{}) ([]interface{}, error) { ... }
func (r *BaseRepository) GetPage(ctx context.Context, entity interface{}, query *PageQuery) (*PageResult, error) { ... }
func (r *BaseRepository) Create(ctx context.Context, entity interface{}) error { ... }
func (r *BaseRepository) Update(ctx context.Context, entity interface{}, updates interface{}) error { ... }
func (r *BaseRepository) Delete(ctx context.Context, entity interface{}, id uint) error { ... }
func (r *BaseRepository) Transaction(ctx context.Context, fn func(tx *gorm.DB) error) error { ... }
```

### 3.2 统一分页查询接口
```go
// PageQuery 统一分页查询参数
type PageQuery struct {
	Page      int         `json:"page" binding:"required,min=1"`           // 页码
	PageSize  int         `json:"pageSize" binding:"required,min=1,max=100"` // 每页大小
	Keyword   string      `json:"keyword"`                                // 搜索关键字
	OrderBy   string      `json:"orderBy"`                                // 排序字段
	Order     string      `json:"order"`                                  // 排序方向
	Filters   interface{} `json:"filters"`                                // 筛选条件
}

// PageResult 统一分页查询结果
type PageResult struct {
	Total    int64       `json:"total"`                                    // 总数量
	Page     int         `json:"page"`                                     // 当前页码
	PageSize int         `json:"pageSize"`                                 // 每页大小
	Data     interface{} `json:"data"`                                     // 数据列表
}
```

### 3.4 事务管理
```go
// Transaction 事务管理器
type TransactionManager struct {
	db *gorm.DB
}

// NewTransactionManager 创建事务管理器
func NewTransactionManager(db *gorm.DB) *TransactionManager {
	return &TransactionManager{db}
}

// Execute 在事务中执行函数
func (tm *TransactionManager) Execute(ctx context.Context, fn func(tx *gorm.DB) error) error { ... }

// 支持回滚策略
type RollbackPolicy int

const (
	RollbackAlways RollbackPolicy = iota // 总是回滚
	RollbackOnError                      // 仅在错误时回滚
	RollbackNever                        // 从不回滚
)
```
