# 插件系统概述

## 简介

Sky-Server 插件系统是一个灵活、可扩展的插件架构，支持动态加载、热重载和生命周期管理。

**核心特性**：
- ✅ 动态加载：运行时加载和卸载插件
- ✅ 热重载：无需重启服务即可更新插件
- ✅ 生命周期管理：Init → Start → Stop → Cleanup
- ✅ 依赖管理：自动解析和加载插件依赖
- ✅ 钩子系统：支持多种扩展点
- ✅ 配置管理：独立的插件配置文件
- ✅ 错误隔离：插件错误不影响主系统

### 插件接口

```go
type Plugin interface {
    // 获取插件信息
    Info() PluginInfo

    // 初始化插件
    Init(ctx context.Context, config map[string]interface{}) error

    // 启动插件
    Start(ctx context.Context) error

    // 停止插件
    Stop(ctx context.Context) error

    // 清理资源
    Cleanup(ctx context.Context) error
}

type PluginInfo struct {
    Name        string   // 插件名称
    Version     string   // 版本号
    Description string   // 描述
    Author      string   // 作者
    Dependencies []string // 依赖的插件
}
```

## 插件生命周期

### 1. 加载阶段

```
1. 扫描插件目录
2. 读取插件元数据（plugin.yaml）
3. 验证插件合法性
4. 解析依赖关系
5. 按依赖顺序加载插件
```

### 2. 初始化阶段

```go
// Init 方法在插件加载后立即调用
func (p *MyPlugin) Init(ctx context.Context, config map[string]interface{}) error {
    // 1. 读取配置
    p.config = config

    // 2. 初始化资源
    p.db = initDatabase()

    // 3. 注册钩子
    p.registerHooks()

    return nil
}
```

### 3. 启动阶段

```go
// Start 方法在所有插件初始化完成后调用
func (p *MyPlugin) Start(ctx context.Context) error {
    // 1. 启动后台任务
    go p.backgroundTask()

    // 2. 注册路由
    p.registerRoutes()

    // 3. 启动服务
    return p.service.Start()
}
```

### 4. 停止阶段

```go
// Stop 方法在插件卸载前调用
func (p *MyPlugin) Stop(ctx context.Context) error {
    // 1. 停止后台任务
    p.stopBackgroundTask()

    // 2. 关闭连接
    p.closeConnections()

    return nil
}
```

### 5. 清理阶段

```go
// Cleanup 方法在插件停止后调用
func (p *MyPlugin) Cleanup(ctx context.Context) error {
    // 1. 释放资源
    p.db.Close()

    // 2. 清理临时文件
    os.RemoveAll(p.tempDir)

    return nil
}
```

## 钩子系统

### 支持的钩子类型

| 钩子名称 | 触发时机 | 用途 |
|---------|---------|------|
| `before_request` | HTTP 请求前 | 请求预处理、认证 |
| `after_response` | HTTP 响应后 | 响应后处理、日志 |
| `before_db_query` | 数据库查询前 | SQL 拦截、审计 |
| `after_db_query` | 数据库查询后 | 结果处理 |
| `on_user_login` | 用户登录时 | 登录日志、通知 |
| `on_user_logout` | 用户登出时 | 清理会话 |
| `on_file_upload` | 文件上传时 | 文件处理、病毒扫描 |
| `on_file_download` | 文件下载时 | 下载统计、权限检查 |

### 注册钩子

```go
func (p *MyPlugin) Init(ctx context.Context, config map[string]interface{}) error {
    // 注册请求前钩子
    hooks.Register("before_request", p.BeforeRequest)

    // 注册响应后钩子
    hooks.Register("after_response", p.AfterResponse)

    return nil
}

func (p *MyPlugin) BeforeRequest(ctx context.Context, req *http.Request) error {
    // 请求预处理逻辑
    log.Printf("收到请求: %s %s", req.Method, req.URL.Path)
    return nil
}

func (p *MyPlugin) AfterResponse(ctx context.Context, resp *http.Response) error {
    // 响应后处理逻辑
    log.Printf("响应状态: %d", resp.StatusCode)
    return nil
}
```

## 热重载

### 工作原理

```
1. 监听插件文件变化
2. 检测到变化后：
   a. 调用旧插件的 Stop()
   b. 调用旧插件的 Cleanup()
   c. 卸载旧插件
   d. 加载新插件
   e. 调用新插件的 Init()
   f. 调用新插件的 Start()
3. 更新插件注册表
```

### 启用热重载

```yaml
# config.yaml
plugin:
  hotReload:
    enabled: true
    watchInterval: 5s  # 检查间隔
```

### 手动触发重载

```bash
# 通过 API
curl -X POST http://localhost:9090/api/v1/plugins/my-plugin/reload \
  -H "Authorization: Bearer YOUR_TOKEN"

# 通过 CLI
./sky-server plugin reload my-plugin
```

## 最佳实践

### 1. 错误处理

```go
func (p *MyPlugin) Start(ctx context.Context) error {
    if err := p.initDatabase(); err != nil {
        return fmt.Errorf("初始化数据库失败: %w", err)
    }

    if err := p.startService(); err != nil {
        p.db.Close() // 清理已初始化的资源
        return fmt.Errorf("启动服务失败: %w", err)
    }

    return nil
}
```

### 2. 资源管理

```go
func (p *MyPlugin) Cleanup(ctx context.Context) error {
    // 使用 defer 确保资源被释放
    defer p.db.Close()
    defer p.cache.Close()
    defer os.RemoveAll(p.tempDir)

    return nil
}
```

### 3. 配置验证

```go
func (p *MyPlugin) Init(ctx context.Context, config map[string]interface{}) error {

        return errors.New("缺少必需的配置项: api_key")
    }

    p.config = config
    return nil
}
```

## 安全考虑

1. **权限隔离**：插件只能访问授权的资源
2. **资源限制**：限制插件的 CPU、内存使用
3. **沙箱执行**：在隔离环境中运行不可信插件
4. **代码审查**：审查第三方插件代码
5. **签名验证**：验证插件包的数字签名

## 故障排查

### 插件加载失败

**问题**：插件无法加载

**排查步骤**：
1. 检查 plugin.yaml 格式是否正确
2. 验证依赖是否已安装
3. 查看日志文件中的错误信息
4. 确认插件文件权限

### 插件崩溃

**问题**：插件运行时崩溃

**排查步骤**：
1. 查看 panic 堆栈信息
2. 检查资源是否正确初始化
3. 验证配置是否正确
4. 使用调试模式运行
