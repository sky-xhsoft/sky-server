## 管理命令

### 后端
```bash
# 查看状态
systemctl status sky-server

# 查看实时日志
journalctl -u sky-server -f

# 启动
systemctl start sky-server

# 停止
systemctl stop sky-server

# 重启
systemctl restart sky-server

# 开机自启
systemctl enable sky-server
```

### nginx / 前端
```bash
# 查看状态
systemctl status nginx

# 重启
systemctl restart nginx

# 重新加载配置
systemctl reload nginx
```
