# 修复云盘录制文件脚本

## 功能说明

该脚本用于批量处理 `live_callback_event` 表中的 `recording_file` 类型事件，自动生成对应的 `cloud_item` 文件夹和文件记录。

## 适用场景

- 直播回调事件已收到，但未生成云盘文件记录
- 之前因为 stream_id 类型问题导致文件创建失败
- 需要批量重新生成录制文件的云盘记录

## 使用方法

### 1. 准备环境

确保本机已安装 Go 1.21+，并且可以访问 MySQL 数据库。

### 2. 下载依赖

在 `scripts` 目录下执行：

```bash
cd scripts
go mod tidy
```

### 3. 确认数据库配置

脚本默认配置（如果需要修改，请编辑 `fix_cloud_item.go`）：

```go
const (
    DBHost     = "127.0.0.1"
    DBPort     = 3306
    DBUser     = "root"
    DBPassword = os.Getenv("DB_PASSWORD") // 通过环境变量 DB_PASSWORD 提供
    DBName     = "skyserver"
)
```

### 4. 运行脚本

```bash
go run fix_cloud_item.go
```

## 脚本处理逻辑

1. **查询所有录制事件**：从 `live_callback_event` 表读取所有 `EVENT_TYPE = 'recording_file'` 的记录
2. **检查文件是否存在**：通过 `ACCESS_URL` 判断文件是否已在云盘
3. **查找直播间**：通过 `stream_id` 关联 `live_room` 表
4. **查找用户ID**：通过直播间的 `CREATE_BY` 字段查找对应用户
5. **创建直播间文件夹**：如果不存在则创建（父目录 ID=391）
6. **创建直播录制文件夹**：在直播间文件夹下创建 "直播录制" 子文件夹
7. **创建文件记录**：插入视频文件记录到 cloud_item 表

## 注意事项

1. **数据库备份**：执行前建议先备份数据库
2. **权限确认**：确保数据库用户有读写权限
3. **父目录ID**：脚本中 `DefaultRoomParentID = 391`，请根据实际情况调整
4. **字符集**：脚本使用 `utf8mb4` 字符集，支持中文
